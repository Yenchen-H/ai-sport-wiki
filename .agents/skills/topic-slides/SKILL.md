# topic-slides：Wiki → 教學 HTML 簡報

## Loop 五件事

| | |
|---|---|
| 🎯 目標 | 只用 `wiki/` 的內容，做一份給「不熟悉主題的人」看的教學 HTML 簡報 |
| 🚧 限制 | 不能用模型自己的知識補內容；不能改 `wiki/` 和 `raw/` |
| ✅ 完成標準 | `scripts/check_slides.py` 全過＋AI 審查無「必修」問題＋使用者看過大綱 |
| 🛑 停止條件 | 全過就停；同一關最多重做 3 輪；覆蓋率關卡發現相關頁面少於 3 頁就停下來回報 |
| ⏰ 觸發 | 使用者說「用 Wiki 做 ○○ 的簡報」 |

## Graph（每一關的產出都是檔案，放在 `slides/<主題>/`）

```
① 檢索 Wiki ─→ ② 覆蓋率關卡 ─→ ③ 證據卡 ─→ ④ 大綱 ─→ ⑤ 使用者確認
   sources.md      不足 → 停          cards/        outline.md     退回 → ④ 或 ①
                                                                     │
⑨ 渲染檢查 ←─ ⑧ 渲染 HTML ←─ ⑦ 忠實度檢查 ←─ ⑥ 逐頁稿 ←────────┘
   溢出 → ⑥ 縮短   index.html     退回 → 只修那頁    drafts/
   │
   └→ ⑩ 交件：report.md
```

| 節點 | 只能看 | 產出 | 不能做 |
|---|---|---|---|
| ① 檢索 | `wiki/index.md` 與各頁 | `sources.md`：相關 Wiki 頁清單 | 讀 `raw/` |
| ② 覆蓋率關卡（程式） | `sources.md` | 通過／停止 | 動手改 |
| ③ 證據卡 | 一張卡只看一個 Wiki 頁 | `cards/*.md`：可用的事實句＋原出處 | 混用其他頁 |
| ④ 大綱 | 證據卡 | `outline.md`：8～15 張，每張列用到哪些卡 | 加卡片以外的內容 |
| ⑤ 確認（人） | `outline.md` | 同意／修改意見 | |
| ⑥ 逐頁稿 | 大綱＋該頁對應的卡 | `drafts/NN.md` | 引用卡片以外的內容 |
| ⑦ 忠實度檢查（AI 審查，獨立子代理） | 逐頁稿＋對應的 Wiki 頁 | `review.md` | 動手改 |
| ⑧ 渲染 HTML | 已通過的逐頁稿 | `index.html` | 改任何一個字 |
| ⑨ 渲染檢查（程式＋截圖） | `index.html` | 檢查結果 | 動手改 |

## 退回路線（錯在哪一關就退回哪一關）

- 某頁講錯 → 退回 ⑥，只重寫那頁，其他頁不動
- 證據卡抄錯 → 退回 ③，重抽那一張
- 文字溢出 → 退回 ⑥ 縮短，不在 ⑧ 硬塞
- 看大綱時發現缺主題 → 退回 ① 補檢索

## 每頁的寫法（簡報讀者是初學者）

- 術語第一次出現：英文＋一句白話，例如「SHAP（一種說明『模型為什麼這樣判斷』的方法）」
- 每頁頁尾標「Wiki：`wiki/concepts/xxx.md`」，並保留原始出處 `[作者 年份, p.頁碼]`
- 一頁最多 5 個重點，每個重點 40 字以內
